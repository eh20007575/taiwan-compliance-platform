# 台灣上市櫃與公發公司「資貸、背保、取處」智慧合規風控平台 (Compliance Copilot)

專為台灣公開發行公司、未上市重要子公司、會計師事務所與承銷團隊打造的垂直領域智能合規風控系統。

---

## 🌟 核心特色

1. **雙軌防線即時合規檢核**：同時比對「第一道防線：公司內部自訂規章」與「第二道防線：金管會《處理準則》法定底線」，支援循環動用授權全額計算與 2 日內重訊公告倒數。
2. **法定「格式五之一」與「格式五之二」附表產出**：依金管會證期局最新標準表格生成，精準計算循環動用期末餘額（註8）、業務往來金額、背保法定代碼 (1)~(7) 與母子/大陸地區標記，支援 CSV 批次匯入/匯出。
3. **一鍵產生「董事會與審計委員會合規簽核報告」**：內建完整核決簽章欄與審查意見，支援一鍵直接匯出正式 Word 檔 (`.doc/.docx`)。
4. **金管會法令與官方問答全文搜尋**：整合證期局歷年實務 FAQ、條文規範與重大訊息公開案例庫。
5. **100% 純前端免伺服器安全運行**：本測試版本所有運算均在使用者本機瀏覽器內完成，機密財務數據絕不外流。

## 🚀 快速開始 (GitHub Pages 部署)

本專案採用純靜態架構，直接開啟 GitHub Pages 即可上線：

1. 將本專案程式碼推送到 GitHub Repository。
2. 進入 Repository 的 **Settings** -> **Pages**。
3. 在 **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
4. 約 30 秒至 1 分鐘後，即可在上方獲得公開測試網址：
   `https://<你的GitHub帳號>.github.io/<Repo名稱>/`

## 📋 外部測試 3 分鐘快速體驗流程

建議受測者依序執行以下 3 項測試任務：

* **任務一：資金貸與他人試算 (短期融通循環動用)**
  1. 點擊「⚡ 一鍵帶入示範案例 (台積電)」。
  2. 勾選「是否為循環動用額度 (Revolving Facility)」。
  3. 點擊「立即執行適法性診斷」，觀察公司辦法 vs 法定底線之雙軌診斷結果與公告申報提醒。
* **任務二：法定申報表格與歷史台帳批次匯入**
  1. 切換至分頁「📑 法定申報附表 (格式五之一/五之二)」。
  2. 點擊表格上方綠色橫幅中的「⚡ 載入示範歷史台帳」。
  3. 檢視合計列是否自動精算，並點擊「📥 下載目前申報表 (CSV)」測試匯出。
* **任務三：董事會合規簽核報告書與 Word 匯出**
  1. 切換至分頁「🏛️ 董事會/審委會簽核報告」。
  2. 檢視完整的適法性審查結論與核決簽章欄位。
  3. 點擊「📝 立即匯出 Word 簽核報告 (.doc)」，確認下載之 Word 檔格式是否合用。
